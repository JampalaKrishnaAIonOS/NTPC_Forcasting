## 🎯 Implementation Details

### 1. Core Modules (7 files, ~2,000 lines of Python)

#### preprocessing.py
- `prepare_series()` - Converts raw data to DatetimeIndex Series
- `func__periodogram()` - Detects seasonal periodicity
- `make_train_test()` - Creates train/test splits with periods

#### ets_model.py, ets_ts_model.py, ets_r_model.py, ets_tsr_model.py
- **ets_model.py**: Base ETS (Exponential Smoothing)
  - 96% confidence intervals
  - RMSE, MAE, coverage metrics
  - Full Plotly visualization

- **ets_ts_model.py**: Trend + Seasonal component
  - STL decomposition (period=7)
  - Separate model for trend+seasonal signal
  - Returns train/validate/forecast splits

- **ets_r_model.py**: Residual component
  - Captures irregular variations
  - Same architecture as TS model
  - Uses residual component from STL

- **ets_tsr_model.py**: Composite (TSR)
  - Combines TS + R predictions
  - Final output for users
  - 96% CI bands from both components

#### events.py
- `detect_events_and_leadtime()` - Identifies PEAK/LOW events
- `early_warning_summary()` - Computes lead time statistics
- `trusted_warning_summary()` - Filters by trust horizon

## 📊 Model Architecture

### ETS (Exponential Smoothing) Pipeline

```
Raw Time Series
    ↓
[Seasonal Decompose (period=7)]
    ├─→ Trend Component
    ├─→ Seasonal Component
    ├─→ Residual Component
    │
    ├─→ Combine T+S → Train ETS TS model
    │
    └─→ Use R → Train ETS R model
           ↓
        [TSR Composite]
           ↓
      TS Predictions + R Predictions
           ↓
    [Final Forecast + CI Bands]
```

### Smoothing Parameters (per plant)
```
BARH:  α=0.002, β=0.02,  γ=0.2
DADRI: α=0.006, β=0.06,  γ=0.6
KUDGI: α=0.008, β=0.08,  γ=0.8
```

### Confidence Intervals
- Method: ±2.06 × σ (96% confidence)
- Applied to both validation and forecast periods
- Visualized as green shaded areas in plots

## 🎓 Model Internals

### ETS Hyperparameters
Each plant has optimized smoothing constants:
- **BARH**: Low smoothing (0.002, 0.02, 0.2) - stable demand
- **DADRI**: Medium smoothing (0.006, 0.06, 0.6) - variable demand
- **KUDGI**: High smoothing (0.008, 0.08, 0.8) - volatile demand

### Metrics
- **RMSE**: Root Mean Squared Error (validation set)
- **MAE**: Mean Absolute Error (validation set)
- **Coverage**: % of test points within 96% CI bands

### Event Thresholds
- **PEAK**: Top 2% of forecasted values (high demand)
- **LOW**: Bottom 2% of forecasted values (supply risk)
