## 🔄 Data Flow

```
User's Excel File (.xlsx)
         ↓
    [HOME PAGE]
    ├─ Validate format
    ├─ Load into pandas DataFrame
    ├─ Store in session_state['df_raw']
    └─ Unlock EDA
         ↓
    [EDA PAGE]
    ├─ 7 exploratory analyses
    ├─ 15+ interactive visualizations
    ├─ Data quality checks
    └─ Unlock Forecast
         ↓
    [FORECAST PAGE]
    ├─ Prepare series (DatetimeIndex)
    ├─ Detect periodicity (FFT)
    ├─ Train/test split
    ├─ Model 1: ETS (Trend+Seasonal)
    ├─ Model 2: ETS (Residual)
    ├─ Model 3: TSR (Composite)
    ├─ Calculate metrics & CI
    ├─ Store plots & data
    └─ Unlock Results
         ↓
    [RESULTS PAGE]
    ├─ Detect PEAK/LOW events
    ├─ Calculate lead times
    ├─ Filter by trust horizon
    ├─ Generate insights
    └─ Download everything
```

## 📊 Model Architecture

```
Raw Time Series (daily data)
    ↓
[SEASONALITY DETECTION]
├─ FFT-based periodogram
└─ Detect dominant period
    ↓
[STL DECOMPOSITION]
├─ Trend (T)
├─ Seasonal (S) 
└─ Residual (R)
    ↓
        ┌─────────────────┬──────────────────┐
        ↓                 ↓                  ↓
    [ETS-TS]         [ETS-R]          [ETS-TSR]
    Trend+          Residual        FINAL
    Seasonal        Component       OUTPUT
    Component
    ├─ α=0.002      ├─ α=0.002      ├─ Combine
    ├─ β=0.02       ├─ β=0.02       │  TS+R
    ├─ γ=0.2        ├─ γ=0.2        │
    └─ (BARH)       └─ (BARH)       └─ ±2.06σ CI
    
         ↓               ↓                 ↓
     Predictions    Predictions    Combined
     + CI bands     + CI bands      Forecast
                                    + CI bands
```
